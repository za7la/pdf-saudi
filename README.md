# pdf-saudi

**منصة سعودية متخصصة في تحويل ومعالجة ملفات PDF**

منصة سريعة وآمنة لتحويل الملفات مع دعم كامل للغة العربية، وخاصة **OCR عالي الدقة** للوثائق الحكومية والمالية.

### ✨ المميزات الرئيسية

- **تحويل PDF إلى Word، Excel، وصور** بدقة عالية
- **OCR عربي متقدم** — يدعم النصوص المطبوعة والممسوحة ضوئيًا بدقة تصل إلى 98%
- معالجة خاصة لـ **فواتير الضريبة والزكاة** السعودية (ZATCA)
- دعم وثائق **أبشر**، **ناجز**، عقود الإيجار، الهويات الوطنية، والإقامة
- ضغط PDF، دمج، تقسيم، إزالة كلمة المرور، وإضافة توقيع إلكتروني
- استخراج الجداول والبيانات تلقائيًا
- واجهة عربية كاملة (RTL) + تصميم حديث وسريع

### 🎯 لماذا pdf-saudi؟

- مصمم خصيصًا للسوق السعودي والخليجي
- دقة عالية في التعرف على النصوص العربية والأرقام
- خصوصية عالية — يتم حذف الملفات تلقائيًا بعد المعالجة
- يدعم الفوترة الإلكترونية والمتطلبات الحكومية

### 🛠️ التقنيات المستخدمة

- Next.js 15 + Tailwind CSS
- Google Cloud Vision + OCR متقدم
- Tap Payments
- Railway Hosting
